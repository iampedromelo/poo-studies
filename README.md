# Estudos de POO

Repositório criado para estudos e exercícios de **Programação Orientada a Objetos (POO)** em Java, no **Instituto Federal de São Paulo - Câmpus São Carlos**

## Conteúdos

* Classes e objetos, Construtores, Sobrecargas de Métodos, Encapsulamento
* Atributos e Métodos Estáticos, Métodos fábrica estáticos, Wrappers para primitivos, Strings, Date/Time

## Tecnologias

* Java
* IntelliJ IDEA

Repositório destinado exclusivamente para estudos e prática.
